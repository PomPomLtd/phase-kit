# /backlog — park it, properly

Read `CLAUDE.md` › Workflow for the backlog's path (default `docs/BACKLOG.md`; none → offer
`/kit-setup`). Add an entry on top of the file in the shape of the `BACKLOG` template
(`phase-kit:templates`, if the file's own first entry does not already show it): a title; **From** (who,
today's date, the context: which phase or conversation); **Why** (what it would improve, for
whom); **Revival trigger** (the event that makes it worth doing); **Shape** (a first idea of the
work, a few lines, with an honest opinion on whether it is worth it). Ask only what you cannot
infer; one question at most. Say in one sentence that it is parked and where. Do not build it,
and do not commit on its own unless the owner asks; the next handoff commits it.
